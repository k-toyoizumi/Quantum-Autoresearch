# Quantum-Autoresearch

AI Agentを活用し、量子アルゴリズム・量子数値線形代数の研究を進めるプロジェクトです。

## 目的

- 学生時代の研究アイデアを再評価し、新規性と研究価値のある課題に発展させる。
- 理論解析、実装、数値実験、論文執筆を、Agentを中心に進める。
- 数学的主張の検証可能性と実験の再現性を確保する。
- 人間の作業負担、介入、品質、コストを記録し、Agentによる研究の自律性を評価する。
- 十分な成果が得られた場合は単著論文の完成・公開を目指す。公開の最終判断は研究者本人が行う。

## 確定した運用方針

### 研究を進めるタイミング

**研究者本人がチャットで依頼した時点で、依頼された範囲の研究を進めます。**

依頼された作業の中ではAgentが自律的に実行・検証・記録します。定期実行、無人の自動再開、常時研究は設定しません。次の依頼に備えて、現在地と再開手順を保存します。

### モデルとコスト

- **Astraはeffortにかかわらず、本人の明示的な事前承認なしに実行禁止です。**
- **Solのhigh以上（high / xhigh / max / ultra）も、本人の明示的な事前承認なしに実行禁止です。**
- この制限は親Agent、サブエージェント、レビュー担当、再試行・代替モデルのすべてに適用します。
- 通常の研究依頼、包括的な「進めて」、過去の利用実績を、上記の承認と解釈しません。
- サブエージェントを使う場合は、モデル・effort・担当範囲を事前に明示して固定し、無断で昇格しません。
- 計算・実験・証明チェックは可能な範囲で通常のプログラムに任せ、不要なLLM呼び出しを抑えます。

詳細は [Agent運用ルール](docs/workflow/agent-policy.md) と [AGENTS.md](AGENTS.md) を参照してください。通常担当の具体的なモデル配分や予算額は、まだ確定していません。

### 文書の管理

- **docs/**：本人との合意・採用が済んだ確定事項、仕様、運用ルール。
- **memo/**：試行錯誤、調査過程、仮説、比較、失敗、レビュー、未採用案。
- 用途ごとにサブディレクトリを分けます。
- **memo以下の文書名はすべて `YYYY-MM-DD_*.md` 形式**とし、日付は日本時間を使います。
- 未確定案はdocsへ移しません。採用時はdocsを更新し、元のmemoから決定先を参照できるようにします。

[文書管理ルール](docs/project/documentation.md) に詳細を記載しています。

### 正しさ・再現性

重要な主張について、仮定・適用範囲・根拠を記録します。Lean 4 / Mathlibは可能な範囲で活用し、**実際の証明チェッカーが成功したものだけをLean検証済みと扱います**。手証明、数値的確認、未検証の予想とは区別します。論文中の主張と検証結果の対応を管理し、失敗・否定的結果も保存します。

関数・スペクトルフィルタ設計を研究の軸とし、応用・下流タスク・未解決性に基づいて具体的な対象を選ぶ方針を確認しました。early FTQCを意識し、回路深さと総コストの双方を評価します。本人には着想・仮定・結果の意味を共有します。

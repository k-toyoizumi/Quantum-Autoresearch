# Agent運用方針

確定日：2026-10-23（日本時間）
更新日：2026-10-24（日本時間）

## 依頼時に進める研究

本人のチャット依頼を開始条件とする。依頼範囲内の調査、理論検討、実装、実験、検証、記録をAgentが自律的に行う。次の依頼を待つ間は研究を自動進行しない。定期起動・自動再開は別途依頼があるまで導入しない。

コミットは進捗の保存点であり、それ自体を会話または依頼された作業の終了条件にしない。依頼範囲の成果を検証し、必要な判断材料まで自律的に整える。2026-10-24の本人認可により、現在のプロジェクト目標・既存予算内での研究方向、比較条件、仮説の採否はAgentに委任され、根拠と不確実性を記録して判断する。追加予算、外部公開、研究目標を越える変更は本人の判断に戻す。Astra/Sol high以上の承認制は維持する。

## モデル利用

| 条件 | ルール |
| --- | --- |
| Astra（全effort） | 本人の明示的な事前承認なしに実行禁止 |
| Sol high以上 | high / xhigh / max / ultraは本人の明示的な事前承認なしに実行禁止 |
| 子Agent・レビュー・再試行 | 同じ制限を適用 |
| サブエージェント | 起動前にモデル・effort・担当範囲を明示し固定。暗黙の継承や昇格を避ける |
| 通常の研究依頼 | 上位モデル・高effortの承認として解釈しない |

モデル・effortの指定と実際に取得できる実行情報を記録する。設定を確認できないものを確認済みと報告しない。本文とAGENTS.mdは運用規約であり、サービス側の課金・モデル設定を機械的に強制する実装が完成したことは意味しない。

通常担当のモデル配分や具体的な消費上限は未確定。LLMを介さず実行できる数値計算・再実験・証明チェックはプログラムに任せ、コストを抑える。

## 品質・引き継ぎ

- 出典、実験、手証明、Lean証明、未検証の仮説を区別する。
- Leanの実行成功なしに形式的証明済みと記載しない。
- 作業単位の目的、実施内容、証拠、失敗、未決事項、再開手順をmemoへ残す。
- 自律性は人間の負担と品質・再現性・コストを併せて評価する。具体的な指標・分母・目標値は今後決定する。

# 研究方向
確定・更新日：2026-10-23（日本時間）

## サマリー
化学・物性のエネルギー推定を応用先とし、early FTQC（初期の誤り耐性量子計算）を意識した、深さ制約下の量子スペクトルフィルタ設計を研究する。低エネルギー状態の抽出から下流のエネルギー推定までを対象に、回路深さと総コストの両方を評価する。この方向の採用を本人が明示的に確定した。新規性や性能改善が確認されたという意味ではない。

## 確定した研究の方向
中心となる問いは、次のとおり。

> 使える回路の深さに上限があるとき、フィルタの形・強さをどう選べば、最終的なエネルギー推定の総コストを小さくできるか？

- QSVT等による関数・スペクトルフィルタの設計を研究の軸とする。
- 低エネルギー状態の抽出を入口とし、化学・物性の具体的な系のエネルギー推定を数値実験に含める方針とする。
- 純粋数学だけで閉じず、応用・下流タスクでの意味を重視する。
- 回路深さと総コストを併せて評価し、状態準備、事前情報の取得、成功確率、失敗再試行、読み出しの費用を含める。
- フィルタだけでなく下流処理を含む最大回路深さを評価する。
- 本人には着想・仮定・結果の意味を共有する。詳細な解析・実装はAgentが担当し、重要な方針・成果評価は本人が判断する。
- 小規模な比較再現から始め、既存法との差を確認して本格研究へ進む。
- 最小特異値の推定は今後の発展候補として残すが、初期研究の中心には置かない。

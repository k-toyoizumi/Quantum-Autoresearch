# 研究方向
確定・更新日：2026-10-24（日本時間）

## サマリー
化学・物性のエネルギー推定を応用先とし、early FTQC（初期の誤り耐性量子計算）を意識した、深さ制約下の量子スペクトルフィルタ関数設計を研究する。下流も浅いエネルギー推定器に固定し、フィルタ関数・強さと推定器を全工程の深さ上限内で共同設計する。physical-versus-virtual filterは公平比較の評価基盤とし、研究の中心をそれ自体の方式比較へ移さない。この方向の採用を本人が明示的に確定した。新規性や性能改善が確認されたという意味ではない。

## 確定した研究の方向
中心となる問いは、次のとおり。

> 使える回路の深さに上限があるとき、利用可能なスペクトル事前情報だけで設計したフィルタ関数の形・強さを浅い下流推定器とどう共同設計すれば、最終的なエネルギー推定の総コストを小さくできるか？

- 研究の中心はフィルタ関数設計とする。関数の係数・中心・幅/強さ・実装次数を、下流の推定器に残る深さ、エネルギーバイアス、shot variance、成功確率と共同で最適化する。
- 下流は浅いエネルギー推定器として評価し、全工程（状態準備、フィルタ、下流推定）の回路深さを同一の硬い上限内に置く。
- physical postselection filterとvirtual/classical `|f|^2` signal reweightingは、同じ期待信号を異なる費用で得る評価軸として比較する。両者の公平比較を、それ自体が研究の主題であるとは確定していない。
- 成功確率・失敗再試行・事前情報取得・測定を含む総費用を比較する。多項式次数/query countとcompiled physical depthを区別する。
- 補助評価として、操作可能な事前情報の下でフィルタが有利となる領域と不利となる領域を調べ、採用条件・棄却条件を導く。
- QSVT/QETU等による関数・スペクトルフィルタを比較するが、特定の実装ライブラリ・下流推定器・入力oracleは未確定。初期の理論比較では同じHadamard signalを提供できるcontrolled-time-evolutionを暫定モデルに使い、block encodingは別のコストモデルとして比較する。
- 化学・物性の具体的な系のエネルギー推定を数値実験に含める方針とするが、対象系は未選定。
- 純粋数学だけで閉じず、応用・下流タスクでの意味を重視する。
- 本人には着想・仮定・結果の意味を共有する。詳細な解析・実装はAgentが担当し、重要な方針・成果評価は本人が判断する。
- 小規模な比較再現から始め、既存法との差を確認して本格研究へ進む。
- 最小特異値の推定は今後の発展候補として残すが、初期研究の中心には置かない。

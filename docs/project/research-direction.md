# 研究方向
確定・更新日：2026-10-24（日本時間）

## サマリー
化学・物性のエネルギー推定を応用先とし、early FTQC（初期の誤り耐性量子計算）を意識した、深さ制約下の量子スペクトルフィルタ設計を研究する。低エネルギー状態の抽出から下流のエネルギー推定までを対象に、回路深さと総コストの両方を評価する。この方向の採用を本人が明示的に確定した。新規性や性能改善が確認されたという意味ではない。

## 確定した研究の方向
中心となる問いは、次のとおり。

> 使える回路の深さに上限があるとき、下流も浅い推定器に固定し、全工程の深さ上限内でフィルタの形・強さをどう共同設計すれば、最終的なエネルギー推定の総コストを小さくできるか？

- 研究の中心は、フィルタと下流の浅いエネルギー推定器を合わせた設計とする。フィルタの次数・形・強さだけでなく、下流推定器に残る深さと精度を共同で考える。
- 全工程（状態準備、フィルタ、下流推定）の回路深さを同一の硬い上限内で評価し、成功確率・失敗再試行・事前情報の取得・測定を含む総費用を比較する。
- 補助評価として、操作可能な事前情報の下でフィルタが有利となる領域と不利となる領域を調べ、採用条件・棄却条件を導く。
- QSVT等による関数・スペクトルフィルタの設計を研究の軸とする。ただし特定のQSVT規約、下流推定器、入力oracleはまだ選定しない。
- 化学・物性の具体的な系のエネルギー推定を数値実験に含める方針とするが、対象系は未選定。
- 純粋数学だけで閉じず、応用・下流タスクでの意味を重視する。
- 本人には着想・仮定・結果の意味を共有する。詳細な解析・実装はAgentが担当し、重要な方針・成果評価は本人が判断する。
- 小規模な比較再現から始め、既存法との差を確認して本格研究へ進む。
- 最小特異値の推定は今後の発展候補として残すが、初期研究の中心には置かない。

# 研究計画
更新日：2026-10-24（日本時間）

## サマリー
化学・物性のエネルギー推定を対象に、深さ制約下の量子フィルタを研究する。理論仮説を立て、実験環境を整備してから予備探索へ進む。新規性・優位性は未確認。

| 段階 | 作業・成果物 | 完了条件 |
| --- | --- | --- |
| 1 | 文献・過去資産の確認。既存法の仮定・保証・費用、再利用候補と依存条件を整理 | 出典・commit・パスと未確認事項を記録し、理論検討に必要な比較表を用意。旧実行環境の再現は段階3へ分離 |
| 2 | 理論的方向性。改善する条件、候補フィルタ、期待する理由、反証条件を整理 | 本人と主要仮説・評価方針を合意。完全な証明は要求しない |
| 3 | 実験環境の検討・構築。実行場所、依存関係、結果保存・再現手順を整備 | 既知の小例で動作確認。旧依存環境の再現と現行Qiskit移植を区別する。同一多項式・基底・正規化・oracle・位相順序で旧実装とPennyLaneの応答/成功率/状態を照合（状態/full-unitaryはglobal phaseを除いて比較）。depth比較ではbackend・basis gates・connectivity・compiler条件を固定 |
| 4 | 人工スペクトルで予備的数値探索 | 仮説の成立範囲・破綻条件を記録し、方向性を再評価 |
| 5 | 最小応用実験の設計。小分子・スピン模型、入力、精度、深さ上限、比較条件 | 本人と実験仕様を合意 |
| 6 | 比較実験。cos・Gaussian・Chebyshev系・フィルタなしと提案候補 | 同条件で再現可能な結果と不確実性を記録 |
| 7 | 継続判断、本格的理論解析・必要なLean検証 | 既存法との差と改善を評価。継続・再設計を本人が判断 |

## 評価原則
状態準備、事前情報取得、成功確率、再試行、下流推定まで含めて最大回路深さと総コストを測る。多項式次数と実回路深さを区別する。理論仮説と安価な数値確認を短く往復し、段階は必要に応じて戻る。Leanは実際のチェック成功のみ検証済みとする。

## 実行範囲
チャット依頼時だけ進める。段階1の静的レビューを完了し、現在は段階2へ渡す重要判断を本人に提示する。環境構築・互換実験は段階3で小規模から行う。モデル利用はAGENTS.mdに従う。

# 文書管理ルール

確定日：2026-10-23（日本時間）

## 配置

| 区分 | 保存する内容 |
| --- | --- |
| docs/project/ | プロジェクト・文書管理の確定事項 |
| docs/workflow/ | 採用済みの作業・検証・モデル運用ルール |
| docs/references/ | 参照する研究資産とその利用手順 |
| memo/planning/ | 計画案、未決事項、初期記録 |
| memo/research/ | 文献調査過程、仮説、理論検討 |
| memo/experiments/ | 実験過程、失敗、結果の解釈 |
| memo/reviews/ | レビュー、指摘、修正の検討 |

今後の必要に応じて、同じ原則でサブディレクトリを追加する。

## 命名・記載

- memo以下のすべての文書名はYYYY-MM-DD_*.mdとする。例：memo/research/2026-10-23_filter-comparison.md。
- 日付は日本時間。実際の作成日を使い、推測で過去日付を付けない。
- 同日の同一テーマは説明部分で区別する。過去の記録を黙って書き換えず、訂正や方針変更を追えるようにする。
- 各memoには目的、確認した事実、仮説・解釈、根拠、未決事項、次の一手を必要に応じて記す。
- docsのファイル名には日付接頭辞を必須としない。

## 確定への移行

検討案はmemoで管理する。本人との合意・採用後にdocsへ確定事項を反映し、根拠となったmemoへのリンクを残す。memoからも確定先へリンクする。研究の主張は、その検証状態を明記し、方針の合意を数学的証明と混同しない。

READMEには目的・基本運用・案内をまとめる。未採用の研究テーマ、モデル配分、指標を確定事項として追加しない。
